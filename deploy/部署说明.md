# MES1 服务器部署指南

## 第一步：买服务器

去**阿里云**或**腾讯云**，搜「轻量应用服务器」：
- 配置：**2核2G** 足够（99元/年）
- 系统选：**CentOS 7.9** 或 **Ubuntu 22.04**
- 地域选离你最近的

买完你会拿到：**服务器公网 IP** + **root 密码**

---

## 第二步：上传文件到服务器

在你 Windows 电脑上打开 **Terminal/PowerShell**，cd 到项目目录：

```bash
# 上传 jar 包 (281MB，等几分钟)
scp target\mes1-0.0.1-SNAPSHOT.jar root@你的IP:/opt/mes1/app.jar

# 上传数据库文件
scp sql\init.sql root@你的IP:/opt/mes1/
scp sql\demo-data.sql root@你的IP:/opt/mes1/

# 上传前端静态文件
scp -r dist\* root@你的IP:/opt/mes1/static/

# 上传部署脚本
scp deploy\setup.sh root@你的IP:/opt/mes1/

# 上传 docker-compose（用已有的）
scp docker-compose.yml root@你的IP:/opt/mes1/
```

---

## 第三步：SSH 连上服务器，执行脚本

```bash
ssh root@你的IP
cd /opt/mes1
chmod +x setup.sh
./setup.sh
```

脚本会自动完成：
- 安装 Docker + Java 17
- 启动 MySQL 8.0 + Redis 7
- 导入数据库 + 演示数据
- 创建 systemd 开机自启服务
- 启动应用

---

## 第四步：开放端口

去云服务器控制台 → **防火墙** → 添加规则：

| 端口 | 用途 |
|---|---|
| 8081 | MES 应用 |
| 3306 | MySQL（建议只开给 127.0.0.1）|
| 6379 | Redis（建议只开给 127.0.0.1）|

---

## 第五步：访问

浏览器打开：`http://你的IP:8081`

默认管理员账号：`admin` / `123456`

---

## 日常管理

```bash
# 查看应用状态
systemctl status mes1

# 重启应用
systemctl restart mes1

# 查看日志
tail -f /opt/mes1/logs/app.log

# 查看错误
journalctl -u mes1 -f

# 更新部署（本地重新打包上传）
mvn package -DskipTests
scp target\mes1-0.0.1-SNAPSHOT.jar root@IP:/opt/mes1/app.jar
ssh root@IP "systemctl restart mes1"
```
